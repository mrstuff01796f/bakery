# �� Bakery Clearance - Мобильное веб-приложение

Современное мобильное веб-приложение (PWA) для продажи продуктов с заканчивающимся сроком годности из пекарен и гастрономических кафе.

## ✨ Особенности

- **🎯 Мобильный дизайн** - оптимизировано для смартфонов и планшетов
- **📱 PWA поддержка** - можно установить как нативное приложение
- **🗺️ Карта города** с расположением пекарен
- **🛍️ Каталог продуктов** с фильтрацией по категориям
- **🛒 Корзина покупок** с динамическим подсчетом
- **💳 Система оплаты** с безопасными платежами
- **⏰ Таймер резерва** на 15 минут
- **👆 Интерактивный слайдер** для верификации
- **🔐 Генерация кода** подтверждения заказа
- **📱 Адаптивный дизайн** для всех устройств

## 🚀 Технологии

- **Frontend**: Next.js 15, React 19, TypeScript
- **Стилизация**: Tailwind CSS 4, DaisyUI
- **Карты**: MapLibre GL
- **Состояние**: Zustand
- **Иконки**: Heroicons
- **PWA**: Service Worker, Web App Manifest
- **Платежи**: Stripe (готово к интеграции)

## 📱 Мобильные особенности

### PWA (Progressive Web App)
- **Установка на главный экран** - работает как нативное приложение
- **Офлайн поддержка** - базовый функционал доступен без интернета
- **Push уведомления** - готово к интеграции
- **Адаптивный интерфейс** - оптимизирован для touch устройств

### Мобильный UX
- **Фиксированная шапка** с компактной навигацией
- **Нижняя навигация** для удобного доступа к основным разделам
- **Touch-friendly элементы** - кнопки и слайдеры оптимизированы для пальцев
- **Горизонтальная прокрутка** для карточек продуктов
- **Свайп-жесты** для навигации

### Адаптивность
- **Mobile-first подход** - дизайн начинается с мобильных устройств
- **Гибкая сетка** - автоматически адаптируется под размер экрана
- **Оптимизированные изображения** - быстрая загрузка на медленных соединениях
- **Touch-оптимизация** - все интерактивные элементы имеют достаточный размер

## 📱 Страницы приложения

### 1. Главная страница (`/`)
- **Карта города** с маркерами пекарен (свайп для навигации)
- **Каталог продуктов** с фильтрами (горизонтальная прокрутка)
- **Возможность добавления в корзину** (touch-friendly кнопки)
- **Отображение скидок** и времени до истечения

### 2. Корзина (`/cart`)
- **Список выбранных товаров** с компактным дизайном
- **Возможность удаления товаров** (swipe-to-delete готов к реализации)
- **Подсчет общей суммы** с крупными цифрами
- **Переход к оплате** (полноширинная кнопка)

### 3. Оформление заказа (`/checkout`)
- **Форма для ввода данных** с оптимизированными полями
- **Сводка заказа** с детальной информацией
- **Имитация процесса оплаты** (готово к Stripe)
- **Информация о безопасности** платежей

### 4. Успешная оплата (`/success`)
- **Таймер обратного отсчета** (15 минут) с крупным шрифтом
- **Интерактивный слайдер** верификации (оптимизирован для пальцев)
- **Генерация кода** подтверждения
- **Пошаговые инструкции** по получению заказа

## 🎨 Мобильный дизайн

- **Современный минималистичный интерфейс** с фокусом на удобство использования
- **Градиентные акценты** в оранжево-янтарной гамме
- **Карточный дизайн** с тенями и скругленными углами
- **Плавные анимации** и переходы (с поддержкой prefers-reduced-motion)

## 🛠️ Установка и запуск

1. **Клонирование репозитория**
```bash
git clone https://github.com/your-username/bakery-clearance.git
cd bakery-clearance
```

2. **Установка зависимостей**
```bash
npm install
```

3. **Запуск в режиме разработки**
```bash
npm run dev
```

4. **Открытие в браузере**
```
http://localhost:3000
```

## 📱 Установка как PWA

### Android (Chrome)
1. Откройте сайт в Chrome
2. Нажмите "Установить приложение" в меню
3. Подтвердите установку

### iOS (Safari)
1. Откройте сайт в Safari
2. Нажмите кнопку "Поделиться"
3. Выберите "На экран «Домой»"
4. Настройте и установите

## 📁 Структура проекта

```
src/
├── app/                    # App Router (Next.js 15)
│   ├── cart/             # Страница корзины
│   ├── checkout/         # Страница оплаты
│   ├── success/          # Страница успешной оплаты
│   ├── globals.css       # Глобальные стили
│   ├── layout.tsx        # Корневой layout с навигацией
│   └── page.tsx          # Главная страница
├── components/            # React компоненты
│   ├── Header.tsx        # Мобильная шапка
│   ├── BottomNavigation.tsx # Нижняя навигация
│   └── Map.tsx           # Компонент карты
└── context/               # Контекст приложения
    └── CartContext.tsx   # Управление корзиной

public/
├── manifest.json          # PWA манифест
├── icon-192x192.svg      # Иконка для PWA
└── icon-512x512.svg      # Большая иконка для PWA
```

## 🔧 Конфигурация

### PWA настройки
В `public/manifest.json` можно изменить:
- Название и описание приложения
- Цвета темы
- Иконки и скриншоты
- Язык и категории

### Переменные окружения
Создайте файл `.env.local`:
```env
NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY=your_stripe_key
STRIPE_SECRET_KEY=your_stripe_secret
```

### Настройка карты
В `src/components/Map.tsx` можно изменить:
- Центр карты (координаты)
- Масштаб по умолчанию
- Расположение пекарен
- Стиль карты
